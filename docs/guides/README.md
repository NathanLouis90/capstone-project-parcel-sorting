# Operating guides and explanations

Follow the [workflow index](../README.md#workflow) in task order and prepare
[each terminal](../terminal_commands.md) before running commands.

Each topic separates procedures from explanations:

| Topic | Instructional files | Explanation file |
| --- | --- | --- |
| Hardware | [Prepare media](hardware/media.md), [scanner/labels](hardware/barcodes.md), [teach waypoints](hardware/waypoints.md), [inspect/recover/home](hardware/homing.md) | [hardware/README.md](hardware/README.md) |
| Recording | [Record episodes](recording/protocol.md), [steps by medium](recording/media.md) | [recording/README.md](recording/README.md) |
| Datasets | [Review/prepare](datasets/preparation.md), [curate](datasets/curation.md) | [datasets/README.md](datasets/README.md) |
| Training | [Matched ACT/DP](training/act_dp.md), [vendor ACT](training/vendor_act.md) | [training/README.md](training/README.md) |
| Runtime | [Run/evaluate cycles](runtime/evaluation.md) | [runtime/README.md](runtime/README.md) |

Procedures state what to do, what to run, what to check, and when to stop.
READMEs explain terminology, command options, stored data, current assumptions,
and how the programs work. Safety requirements and important software
limitations remain linked from the action they affect.

The existing `recording/README.md` now contains explanations. Its previous
startup and recording procedure is in [recording/protocol.md](recording/protocol.md).
The [documentation README](../README.md#terminal-syntax) explains shared terminal
syntax and dry-run effects separately from the terminal procedure.
